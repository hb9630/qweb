# 对话主导布局（chat-first layout）设计

日期：2026-11-07 · 状态：已与用户逐段确认

## 背景与动机

现状是 VSCode 式三栏（Activity Bar | 目录树 | 编辑器 | 对话右侧 ~420px），对话只是并列的一栏。
目标：**对话是主角，铺满整个宽度**；目录树和编辑器是对话派生出的辅助浮层。
层级链：对话（标题栏左上）→ 选工作目录 → 目录树 → 打开文件 → 编辑器——父子链而非并列。

## 布局骨架

```
┌──────────────────────────────────────────────────────────────┐
│ [📁 ~/Code/ccweb] [▾] [⇄ 换目录]     会话标题      （标题栏,全宽）│
├───────────────┬──────────────────────┬───────────────────────┤
│ ▓ 目录树(浮层)  │ ▓ 编辑器(浮层)        │                       │
│ ▓ 从标题栏下方  │ ▓ 紧贴树右侧          │   对话(底层,铺满全宽)   │
│ ▓ 垂到到底     │ ▓                    │                       │
└───────────────┴──────────────────────┴───────────────────────┘
▓ = 浮层：实底 + 阴影 + 圆角右侧，盖在对话上，不挤占布局
```

- **标题栏** = 现 ChatPanel 头部升格为全局全宽栏（仍在 ChatPanel 内渲染）。
- **对话**是底层画布，结构上永远 `absolute inset-0` 铺满。
- **树浮层**：`left:0`、从标题栏下沿（h-8）垂到底，默认宽 280px，右缘拖宽 190~460。
- **编辑器浮层**：`left = 树开 ? 树宽 : 0`，同垂到底，默认宽约 46vw，右缘拖宽 360~70vw；
  树开/关时编辑器整体平移贴靠，不重叠。窄屏宽度 clamp 到 vw。
- **内容列避让**：浮层开时，对话内容列与输入框（`max-w-5xl mx-auto`）在剩余可见区
  重新居中（经 `chatInset` prop 传入浮层总宽）；浮层全关回屏幕居中。底层铺满不变。
- **手机端统一**：删除 <768px 的"顶部三选一 tab"分支与 visibility 叠放——手机桌面同一套
  结构（标题栏 + 对话全屏 + 浮层），浮层接近全屏宽，靠面板 X 退出。

## 标题栏三件套（左上一组）

1. **cwd chip**：目录图标 + 路径（home 下显示 `~/…` 相对路径，外显绝对路径）。
   点击 = 开/关目录树浮层（树开关的唯一入口，不再有独立图标）。
2. **紧邻下拉 ▾**：历史工作目录列表（`ccweb.recents`，≤5 条），点选直接切换。
3. **"换目录"按钮**：弹 DirPicker 选择器。

## 浮层各自独立关闭

- 树、编辑器**各自头部有 X，独立关闭**（互不影响）——相当于把原三栏的树/编辑器搬到标题栏
  下面浮起，关闭语义沿用原布局。
- 点开文件后**树不收起**：树留着，编辑器贴上来。
- 编辑器退场两条路：自身 X，或**最后一个文件 tab 关闭 → 自动收起**（现有语义不变，Editor.tsx:335）。
- cwd chip 可单独开关树；关树时编辑器原地不动（左移贴边）。

## DirPicker（目录选择器，新组件）

- 面板顶部：面包屑路径 + 上一级按钮——**自由上下导航**（与树的区别：树锁死在工作目录内，
  picker 负责走出去选新目录；home 子树外显示绝对路径）。
- 中部：当前层级目录列表（只列目录）；**行 hover 行尾出 ✓ 可直选该目录**（不进入）。
- 底部确认栏：当前候选路径 + **醒目 ✓ "选这个目录"**（明确的主操作，不用双击手势）。
- Esc / 点击外部关闭。
- 选定后联动（复用现有 `setWorkspace`，不改后端）：换目录 = 新会话（notice 提示保留）；
  树重新扎根并自动展开（含此前关闭的情况）；写入 `ccweb.recents`。

## Explorer 删减（树锁死工作目录内）

删：`browse` 状态（根恒等于工作目录）、".." 上溯行、树顶路径栏 / Home 按钮、
右键菜单"设为工作目录"（换目录唯一入口 = 标题栏）、键盘 ← 的父级上跳。
保留：上传 / 重命名 / 删除 / 多选 / 拖拽 / 框选 / 键盘导航等全部文件管理功能。
